Ashapp v0.0.6 introduces a compact desktop workspace, direct connection copying and the warm Carbon logo.

- The resizable window starts at approximately 520 × 760, adjusted to fit the display. Servers, Templates, Manage, Clients and Access appear along the bottom; wider windows use a sidebar. The selected SSH endpoint and session state stay visible, and switching servers preserves independent sessions. Forms support scrolling and larger text.
- **Copy connection** copies an existing AmneziaWG configuration or VLESS link without displaying its keys. Export dialogs retain format selection, protected file saving and QR codes. VLESS QR codes always encode the original link; exports never regenerate client keys or UUIDs. Imported configurations remain hidden.
- The approved warm Carbon A + small sh mark is shared by the toolbar, Windows executable/Setup and macOS application icons. Its editable SVG and generation tool are included in the source. macOS Installer keeps its system appearance.
- The saved System / Light / Dark appearance choice, application updater, security fixes, templates, SOCKS5 and independent AmneziaWG/VLESS services are retained.

**Updating from v0.0.4 or v0.0.5:** open **Check for updates**, download v0.0.6 and choose **Install update** when all server tasks are idle. Complete Windows Setup/macOS Installer and reopen the installed app. Windows Setup installs per user; macOS Installer replaces Applications/Ashapp.app. Portable copies elsewhere remain separate. Saved server profiles, templates and OS-vault credentials live outside the application bundle. A complete installer update and credential-retention check still require manual validation.

The verified updater, v0.0.4 security fixes, AmneziaWG/VLESS client management, saved key/QR exports, authenticated SOCKS5, templates and independent multi-server sessions are retained. Native installers, ZIP bundles, source archive, build manifests and SHA256SUMS come from one source commit and are published only after all three native targets pass CI.

**Compatibility and validation limits:** Windows packages are unsigned; macOS uses an ad-hoc app signature without Developer ID or notarization. OS security prompts remain. Replacing an ad-hoc Mac build may prompt for Keychain access again. Windows may require Microsoft's Visual C++ x64 Runtime; development SDKs are not required. Checksums establish integrity and provenance ties assets to CI/source; neither is independent publisher signing or proof of reproducible builds. The arm64 artifact is cross-compiled on Intel; physical Apple Silicon and macOS sandbox installer/save-panel testing remain pending. Fresh VPS provisioning and live dual-protocol traffic remain unverified. See README and docs/UPDATES.md for prerequisites and trust limits.

Previous release commits, tags and assets are retained. No passwords, private keys, local profiles, security-audit artifacts or development toolchains belong in release source.
