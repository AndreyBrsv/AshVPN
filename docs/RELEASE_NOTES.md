Ashapp v0.0.4 adds application updates and security fixes. Download Windows Setup or the macOS installer for Intel/Apple Silicon; complete ZIP bundles remain available. Native archives, installers, source, manifests and SHA256SUMS must come from the same verified source commit. Releases are public.

**App updates:** use the toolbar button for daily stable-release checks, manual checks, cancellable download and installation confirmation. Files are checked against GitHub SHA-256 digests, SHA256SUMS and the build manifest, then hashed again before native handoff. Installation waits for tasks on every server, including unselected sessions, and gates new operations before closing the app. Windows Setup installs per user; macOS Installer replaces Applications/Ashapp.app. Profiles, templates and OS-vault passwords stay outside the application bundle. Published v0.0.3 has no updater: install v0.0.4 manually once to get this feature for subsequent releases.

**Security fixes:** Debian AmneziaWG package trust uses the verified full public signing fingerprint and a dedicated Signed-By keyring, replacing the short-ID/global apt-key bootstrap. Conflicting existing sources are refused. Automatic root SSH disabling refuses conditional Match/include policies it cannot prove safe. Windows/macOS private exports replace destinations with fresh protected files, preserving the old bytes seen by prior readers/hardlinks. VLESS executable/config ancestors and runtime permissions are corrected under a restrictive umask without widening existing private directories.

Existing AmneziaWG client management, saved key/QR exports, per-device VLESS + Reality + XTLS Vision, authenticated SOCKS5, templates and independent multi-server sessions are retained. Services remain separate. VLESS uses checksum-pinned sing-box 1.14.4; Xray 26.10.31 and sing-box 1.14.4 passed earlier local traffic/revocation checks. Fresh Linux/VPS provisioning and live dual-protocol traffic remain unverified.

**Compatibility and validation limits:** checksums/HTTPS trust GitHub and are not independent publisher signatures. Windows binaries/installers are unsigned; macOS has an ad-hoc app signature, without Developer ID or notarization. OS security prompts remain. Replacing an ad-hoc Mac build may prompt for Keychain access again. Windows may need Microsoft's Visual C++ x64 Runtime; development SDKs are not required to run the app. A successful native build or mocked launcher does not prove an end-to-end installer update, macOS sandbox handoff or save-panel behavior. The arm64 artifact is cross-compiled on an Intel Mac; physical Apple Silicon testing is still required. See README and docs/UPDATES.md for prerequisites, verification and update trust limits.

Previous release commits and tags are retained. No passwords, private keys, local profiles, security-audit artifacts or development toolchains belong in release source.
